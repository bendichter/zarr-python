Reading part of an uncompressed chunk now fetches only the bytes it needs. When `BytesCodec` is the only codec, a selection is read with a single byte range request covering the rows along the first axis that it touches, instead of the whole chunk. A selection that touches a single row is narrowed in the same way along the next axis, so `arr[t, y0:y1, x0:x1]` fetches only rows `y0` to `y1` of frame `t`. Chunks with a compressor or any other codec are read whole, as before.
